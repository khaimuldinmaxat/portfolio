# maxatkhaimuldin.com

Сайт-портфолио Максата Хаймулдина, продуктового дизайнера (UX/UI): главная, кейсы SPOTS, cult.Jenos и Hero’s Journey, резюме в PDF.

Статичный сайт без сборки: HTML, CSS и немного JavaScript. Макеты — в Figma.

- `index.html` — главная
- `spots/`, `cult-jenos/`, `heros-journey/` — страницы кейсов
- `cv/` — резюме
- `assets/` — стили, скрипт, шрифты (Geologica и Inter, лицензия OFL), иконки и картинки в WebP
